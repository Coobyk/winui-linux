# winui-theme

Fluent Design tokens for winui-linux — pure data, no rune dependency. Contract: [docs/ARCHITECTURE.md](../../docs/ARCHITECTURE.md).

- `Color` (sRGBA f32), hex/ARGB parsing, compositing, contrast, OKLab.
- `Tokens` — every colour in WinUI's `Common_themeresources_any.xaml` for Light and Dark
  (generated by `tools/gen_tokens.py`), plus elevation-border gradients.
- `Theme::{light, dark, with_accent}` — `with_accent` derives a 7-step `AccentRamp`.
- `TypeRamp` (Segoe UI Variable), `spacing`, `radii`, `sizes`, `motion`.

Regenerate tokens: `python3 crates/winui-theme/tools/gen_tokens.py` (fetches the pinned upstream XAML).
Try an accent: `cargo run -p winui-theme --example ramp -- '#881798'`.
